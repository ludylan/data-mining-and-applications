# 專案地圖 (Map)

這張地圖是我們討論的四個階段，大家隨時可以在 GitHub 上瀏覽：

```mermaid
flowchart TD
    subgraph S1 ["1. 觀察 (你看到了什麼？)"]
        A["新聞 / 財報 / 市場公告 / 技術指標"]
    end

    subgraph S2 ["2. 處理 (你打算怎麼處理這件事？)"]
        B["爬蟲抓取 / 數據過濾 / 重點萃取 / 關鍵字篩選"]
    end

    subgraph S3 ["3. 提供資訊給 AI (AI 可以參考哪一部分？)"]
        C1["【短】一覽摘要（讓 AI 快速判斷要不要看）"]
        C2["【中】關鍵數據與推論重點（需要時進一步查看）"]
        C3["【長】原始段落與證據（供深入查閱或二次推論）"]
    end

    subgraph S4 ["🎯 決策與因果 (大家一起拼出來)"]
        D["AI 綜合查閱各方資訊 ➔ 因果推導 ➔ ETF 買賣決策"]
    end

    A --> B
    B --> C1 & C2 & C3
    C1 & C2 & C3 -. 提供查詢 .-> D
```
