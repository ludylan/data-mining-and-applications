## 1. 模組職責與為什麼需要它？
這個模組不連網、不呼叫 AI，它是整個系統的**「靜態憲法與產業地圖」**：
1. 鎖死官方允許交易的 **150 檔股票白名單**（依據 [`docs/150_v1.md`](../150_v1.md)）。
2. 自動區分每檔股票是**上市（`twse`，100 檔）**還是**上櫃（`tpex`，50 檔）**，避免 D-Plan 填錯 `sources.authority`。
3. 定義 **「上下游供應鏈因果圖譜」**，讓 M3 漏斗在看到龍頭股異動時，知道該把哪些上櫃／中小型供應鏈拉進來。
4. 存放 **30 檔主動型 ETF（[`docs/etf_v1.md`](../etf_v1.md)）** 的權重基準，供 M5 驗算 Active Share $\ge 15\%$。

## 2. 內部子模組與資料結構定義

### 子模組 1.1：150 檔白名單與市場路由表 (`UNIVERSE_150`)
每檔股票記錄以下屬性：
```python
@dataclass(frozen=True)
class StockMeta:
    ticker: str          # 4位數代號，如 "2330", "5274"
    name: str            # 中文名稱，如 "台積電", "信驊"
    market: str          # "twse" (上市100檔) 或 "tpex" (上櫃50檔)
    chain_group: str     # 所屬主供應鏈聚落代號
    role: str            # "leader" (上游/大型權值領頭羊) 或 "follower" (中下游/高彈性供應鏈)
    max_weight: float    # 2330 為 0.25，其餘 149 檔為 0.10
```

### 子模組 1.3：30 檔主動型 ETF 前 15 大持股基準 (`ACTIVE_ETF_BENCHMARKS`)
