# 範例：情緒指標與新聞觀察想法

> 這是一個示範檔案。組員可以直接在 GitHub 網頁上新增類似這樣的檔案，留下自己的想法或腳本！

### 1. 我今天看到了什麼東西？
* **資料來源**：鉅亨網即時新聞、經濟日報。
* **觀察標的**：台股大盤、主要半導體與高股息 ETF（如 0050、0056）。

### 2. 我打算怎麼處理這個部分？
* 寫一個 Python 爬蟲抓取每日盤前與盤後的頭條新聞。
* 用簡單的關鍵字或小模型做「情緒判斷」（看多、看空、或是單純陳述事實）。

### 3. 我覺得 AI 可以參考哪一個部分？
* **短（概要）**：盤前國際股市大跌，市場恐慌情緒升高。
* **中（要點）**：半導體板塊多檔個股早盤重挫逾 3%，外資近期持續提款。
* **長（原文）**：附上當天主要財經新聞的原文段落供深度查證。
